# frontend

Replace this directory with the Angular Git submodule.

Required frontend baseline:
- Angular
- Tailwind CSS
- Ubuntu Google Font only
- Brand primary `#9470F8` / `rgb(148 112 248)`
- Off-white/grey neutral surfaces
- Modern, simple Bento UI system
- Semantic shared UI primitives under `src/app/shared/ui`
- Brand/design requirements from `../docs/design/`
